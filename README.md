# Grafurile în lumea reală

Site educațional interactiv pentru proiectul de Informatică (Clasa a XI-a) — capitolul *Grafuri neorientate, grafuri orientate și arbori*.

## Cum deschizi site-ul

Deschide fișierul `index.html` în browser (dublu-click sau drag & drop în Chrome/Edge/Firefox).

Alternativ, pornește un server local:

```bash
cd grafuri-educatie
python -m http.server 8080
```

Apoi accesează: http://localhost:8080

## Structura proiectului

| Secțiune | Conținut |
|----------|----------|
| Pagina principală | Titlu, echipă, introducere |
| Teorie | Grafuri, arbori, reprezentări |
| Probleme rezolvate | 8 probleme cu cod C++ |
| Exerciții | 10 probleme cu soluții ascunse |
| Quiz | 15 întrebări interactive |
| Rebus | 11 termeni tematici |
| Aplicații | 8 exemple din viața reală |
| Simulator | Vizualizare BFS/DFS |
| Constructor | Creează grafuri + matrice/listă live |
| Galerie | Diagrame, animații SVG, videoclipuri |
| Cuprins | Navigare rapidă pe homepage |
| Bibliografie | Surse și referințe |

## Personalizare

- Înlocuiește numele echipei în `index.html` (secțiunea „Echipa noastră”).
- Modifică conținutul teoretic sau problemele în fișierele din `js/`.

## Tehnologii

HTML5, CSS3, JavaScript vanilla — fără dependențe externe (funcționează offline după prima încărcare a fonturilor Google).
